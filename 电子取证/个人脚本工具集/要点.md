### 法规与政策类

#### 《网络安全法》颁布时间
- 正式通过：2016年11月7日（全国人大常委会）
- 正式施行：2017年6月1日

#### 数据出境安全评估
- **有效期**：3年
- **重新评估条件**：当跨境数据量、用途、处理方式或第三方状况发生重大变化时

#### 数据安全风险评估四要素
1. **数据资产价值** - 数据敏感度及业务影响程度
2. **威胁可能性** - 攻击者动机与能力
3. **脆弱性程度** - 系统漏洞与薄弱环节
4. **影响严重性** - 事件造成的业务、法律及声誉损失

#### 数据治理安全目标
- ✅ 确保数据质量（标准化、清洗、校验）
- ✅ 提高数据可用性（权限管理、备份容灾）
- ✅ 保护数据安全（分级分类、加密脱敏）
- ❌ 加快处理速度（属性能优化范畴）

🔍 **相关查询命令**：
```bash
# 查找系统中包含敏感数据的文件
find / -type f -name "*.db" -o -name "*.sql" -o -name "*.csv" 2>/dev/null

# 检查数据文件权限设置
ls -la /path/to/sensitive/data/

# 查找包含敏感信息的配置文件

# 检查数据分类标记
ls -la /data/ | grep -E "(public|internal|confidential|secret)"
```

### 技术原理类

#### 网络协议识别
- **协议类别**：TCP/IP协议族、HTTP、FTP等
- **例外情况**：WPA为无线局域网加密标准，非通用网络通信协议

#### 网络分割作用
- 🔒 **提升安全性**：隔离不同安全级别的业务域，限制攻击横向扩散
- 🚀 **优化性能**：缩小广播域，减少网络拥塞
- ❌ 不会节省存储空间或增加物理带宽

#### 网络威胁情报价值
提供关于潜在或已发生攻击的实时数据，包括：
- 攻击指标（恶意IP/域名、漏洞利用链）
- 攻击者战术、技术与流程（TTPs）
- 上下文分析与响应建议

#### XXE漏洞前提条件
XML External Entity漏洞成立需满足：
1. 使用不安全的XML解析器
2. 允许外部实体解析
3. 处理不可信XML输入

🛡️ **防护建议**：禁用DTD和外部实体解析

🔍 **相关查询命令**：
```bash
# 查看系统支持的网络协议
cat /etc/protocols

# 检查网络连接状态
netstat -tuln
ss -tuln

# 分析网络流量协议分布
tcpdump -i any -nn -c 100

# 查看VLAN配置
cat /proc/net/vlan/config

# 检查iptables规则
iptables -L -n -v

# 查看网络接口信息
ip addr show

# 检查Java应用中是否存在危险的XML解析器配置
grep -r "setFeature.*http://apache.org/xml/features/disallow-doctype-decl.*false" /path/to/app/

# 查找XML解析相关代码
grep -r "XMLReader\|SAXParser\|DocumentBuilder" /path/to/source/code/

# 检查PHP应用中XML解析设置
grep -r "libxml_disable_entity_loader" /path/to/php/code/
```

### 服务器配置与日志分析

#### 防火墙端口控制
通过`iptables`或`firewalld`规则精确控制访问源：
```bash
-A IN_public_allow -s 10.10.100.100/32 -p tcp --dport 18833 -j ACCEPT
```
上述规则表明仅允许10.10.100.100访问18833端口

#### SSH登录日志分析
提取指定日期连接IP的命令：
```bash
grep -a /var/log/secure | egrep -i 'Accepted|Connection from' \
 | grep -oE '([0-9]{1,3}\.){3}[0-9]{1,3}' | sort -u
```

#### 恶意定时任务排查
检查计划任务中隐藏的恶意行为：
```bash
# 检查定时任务
crontab -l
/etc/crontab
/etc/cron.d/*

# 提取脚本中的IP地址
grep -oE '([0-9]{1,3}\.){3}[0-9]{1,3}' /usr/local/bin/remote_task.sh | sort -u
```

#### 命令注入防范对比
| 命令 | 安全性 | 说明 |
|------|--------|------|
| `cat ../../flag.txt` | ❌危险 | 直接读取文件内容 |
| `grep ../../flag.txt` | ⚠️仍需防范 | 将参数误作搜索模式 |

🛡️ **最佳实践**：
- 白名单验证输入
- 使用`escapeshellarg()`处理参数
- 避免直接调用shell

🔍 **相关查询命令**：
```bash
# firewalld详细规则查看
firewall-cmd --list-all

# iptables详细规则查看
iptables -L -n -v --line-numbers

# 查看特定服务的防火墙规则
firewall-cmd --list-services

# 检查SSH配置文件安全设置
grep -E "PermitRootLogin|PasswordAuthentication|PubkeyAuthentication" /etc/ssh/sshd_config

# 查看SSH登录失败记录
grep "Failed password" /var/log/secure

# 统计SSH登录尝试来源IP
awk '/Accepted/{print $11}' /var/log/secure | sort | uniq -c | sort -nr

# 检查所有用户的crontab
for user in $(cut -f1 -d: /etc/passwd); do crontab -u $user -l 2>/dev/null; done

# 查找系统级定时任务
ls -la /etc/cron.*

# 检查可写的重要系统目录
find /etc/cron.* /var/spool/cron -perm -002 -ls 2>/dev/null

# 检查Web应用中危险函数使用情况
grep -r "shell_exec\|exec\|system\|passthru" /path/to/web/app/

# 查找可能的命令拼接代码
grep -r "\." /path/to/code/ | grep -E "(shell_exec|exec)"

# 检查输入验证实现
grep -r "validate\|filter\|sanitize" /path/to/input/handling/

# 实时监控安全相关日志
tail -f /var/log/secure /var/log/messages | grep -i "fail\|error\|warning"

# 分析Web访问日志中的异常请求
awk '{print $1}' /var/log/httpd/access_log | sort | uniq -c | sort -nr | head -20

# 检查系统日志中的安全事件
grep -i "security\|attack\|intrusion" /var/log/messages
```

### 数据库配置查询

#### 查询只读用户
```sql
SELECT GRANTEE
FROM information_schema.SCHEMA_PRIVILEGES
WHERE TABLE_SCHEMA = 'website'
GROUP BY GRANTEE
HAVING SUM(CASE WHEN PRIVILEGE_TYPE <> 'SELECT' THEN 1 ELSE 0 END) = 0;
```

#### 关键参数配置
| 参数 | 默认值 | 说明 |
|------|--------|------|
| `default_password_lifetime` | 0（永不过期） | 密码有效期（天） |

通过SSH连接到系统后，您可以获取大量系统信息。以下是常见的几类系统信息及获取方法：

## 基本系统信息

1. **操作系统版本信息**
   ```bash
   uname -a              # 内核版本等信息
   cat /etc/os-release   # 操作系统发行版信息
   lsb_release -a        # Linux标准基础版本信息
   ```

2. **主机信息**
   ```bash
   hostname              # 主机名
   hostname -I           # IP地址
   whoami                # 当前用户
   id                    # 当前用户ID和组信息
   uptime                # 系统运行时间
   ```

3. **硬件信息**
   ```bash
   lscpu                 # CPU信息
   free -h               # 内存使用情况
   df -h                 # 磁盘空间使用情况
   lsblk                 # 块设备信息
   lspci                 # PCI设备信息
   lsusb                 # USB设备信息
   ```

4. **网络信息**
   ```bash
   ip addr show          # 网络接口信息
   netstat -tuln         # 网络连接状态
   ss -tuln              # 套接字统计信息
   ```

5. **进程和服务信息**
   ```bash
   ps aux                # 所有运行中的进程
   top                   # 实时进程监控
   systemctl list-units  # systemd服务状态(较新的Linux发行版)
   service --status-all  # 服务状态(较老的系统)
   ```

6. **用户和权限信息**
   ```bash
   who                   # 当前登录用户
   last                  # 最近登录记录
   cat /etc/passwd       # 用户账户信息
   cat /etc/group        # 组信息
   ```

7. **系统日志**
   ```bash
   journalctl            # systemd日志(新系统)
   tail -f /var/log/syslog  # 系统日志实时查看(Ubuntu/Debian)
   tail -f /var/log/messages # 系统日志实时查看(RHEL/CentOS)
   ```


在系统中查找特定的flag文件有多种方法，这里我介绍几种常用的查找方式：

## 基本文件查找命令

### 1. 使用 find 命令
```bash
# 查找名为 flag 的文件
find / -name "flag" 2>/dev/null

# 查找以 flag 开头的文件
find / -name "flag*" 2>/dev/null

# 查找以 .txt 结尾的文件
find / -name "*.txt" 2>/dev/null

# 在当前目录及子目录查找 flag 文件
find . -name "flag*" 2>/dev/null

# 根据文件大小查找（例如10字节左右的flag文件）
find / -size 10c 2>/dev/null
```

### 2. 使用 locate 命令（需要预先建立索引）
```bash
# 查找包含 flag 的文件
locate flag

# 更新 locate 数据库
sudo updatedb
```

### 3. 使用 grep 在文件内容中搜索
```bash
# 在所有 .txt 文件中搜索 flag
grep -r "flag" / --include="*.txt" 2>/dev/null

# 在当前目录下搜索包含 flag 字样的文件内容
grep -r "flag" . 2>/dev/null
```

### 4. 根据文件权限查找
```bash
# 查找只有特定用户可读的文件
find / -type f -perm 0600 2>/dev/null

# 查找所有人可读的文件
find / -type f -perm -o=r 2>/dev/null
```

### 5. 查找最近修改的文件
```bash
# 查找最近1天内修改的文件
find / -type f -mtime -1 2>/dev/null
```

## 针对CTF或渗透测试的常用方法

### 1. 查找常见的flag格式
```bash
# 查找包含 flag{...} 格式的文件
grep -r "flag{" / 2>/dev/null

# 查找包含 FLAG 格式的文件
grep -r "FLAG" / 2>/dev/null

# 查找包含特定哈希格式的内容
grep -r "0xf4678858b2b588224636b8522b729e7722d32fc491da849ed75b3fdf3c84f542" / 2>/dev/null
```

### 2. 查找隐藏文件
```bash
# 查找以 . 开头的隐藏文件
find / -name ".*" 2>/dev/null

# 查找隐藏的flag文件
find / -name ".flag*" 2>/dev/null
```

### 3. 查找特定目录
```bash
# 查找用户主目录下的flag文件
find /home -name "flag*" 2>/dev/null

# 查找网站目录下的flag文件
find /var/www -name "flag*" 2>/dev/null

# 查找临时目录下的flag文件
find /tmp -name "flag*" 2>/dev/null
```

### 4. 使用通配符查找多种可能的flag文件名
```bash
# 查找多种可能的flag命名方式
find / -name "flag*" -o -name "FLAG*" -o -name "*flag*" 2>/dev/null
```
