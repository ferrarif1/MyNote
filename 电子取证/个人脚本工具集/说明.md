# 磁盘 / 镜像 / 内存 取证基础操作（只读、安全、可复现）


> 运行环境假设：Linux（有 root 权限用于挂载 qemu-nbd 或 guestmount），已安装 `vol`（Volatility）、`qemu-nbd`、`libguestfs-tools`（guestmount）、`xxd`、`strings`、`grep`、`sha256sum`、`xxd`、`jq`（可选）。

## 重要安全与证据链提醒（先读三秒）

1. **绝对不要**在原始镜像上写操作。所有写操作都必须在拷贝上或只读挂载。
2. **保存原件哈希**（sha256）并把你运行的命令记录（commands.txt）。
3. 如果发现密码/私钥/敏感信息，严格按单位合规流程处理，不要随意上传或贴到公共网络。

# 脚本 A — 磁盘镜像快速检测（`disk_quick.sh`）

保存为 `disk_quick.sh`，随后 `chmod +x disk_quick.sh`，用法 `./disk_quick.sh ide0_disk.vmdk`
（会输出 hashes、strings 扫描、偏移定位、导出 chunk，并生成 report 文件夹）

```bash
#!/bin/bash
set -euo pipefail

IMG="$1"
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
OUTDIR="disk_report_${TIMESTAMP}"
mkdir -p "$OUTDIR"

# 1. 基本校验（sha256）
echo "[*] computing sha256..."
sha256sum "$IMG" > "$OUTDIR/$(basename $IMG).sha256"
echo "sha256 saved to $OUTDIR/$(basename $IMG).sha256"

# 2. 快速字符串扫描（常见关键词）
echo "[*] strings scan (this may take a while)..."
strings "$IMG" | egrep -n 'IPADDR|BOOTPROTO|ifcfg-|ONBOOT|DEVICE|HWADDR|PASSWORD|DefaultPassword|ssh-rsa|BEGIN RSA PRIVATE KEY' > "$OUTDIR/strings_hits.txt"
wc -l "$OUTDIR/strings_hits.txt"

# 3. 精确字节偏移（用于导出上下文）
echo "[*] locating byte offsets..."
grep -aob -E 'IPADDR=|BOOTPROTO=|ifcfg-|ONBOOT=|DEVICE=|DefaultPassword|BEGIN RSA PRIVATE KEY' "$IMG" > "$OUTDIR/offsets.txt" || true
wc -l "$OUTDIR/offsets.txt"

# 4. 按偏移导出上下文（前后512字节）
mkdir -p "$OUTDIR/chunks"
while IFS=: read -r off match; do
  outbin="$OUTDIR/chunks/chunk_${off}.bin"
  outtxt="$OUTDIR/chunks/chunk_${off}.txt"
  start=$(( off > 512 ? off - 512 : 0 ))
  dd if="$IMG" bs=1 skip=$start count=1024 status=none of="$outbin"
  strings "$outbin" > "$outtxt"
done < "$OUTDIR/offsets.txt" || true

# 5. 试图挂载（可选：需要 root + qemu-nbd）
echo "[*] attempting read-only mount via qemu-nbd (requires root)..."
if command -v qemu-nbd >/dev/null 2>&1; then
  if [ "$(id -u)" -ne 0 ]; then
    echo "  (skipped qemu-nbd mount: need root)"
  else
    modprobe nbd max_part=8 || true
    qemu-nbd -c /dev/nbd0 "$IMG"
    sleep 1
    # 列分区并尝试只读挂载每个分区
    for p in /dev/nbd0p*; do
      mountpoint="$OUTDIR/mnt_${p##*/}"
      mkdir -p "$mountpoint"
      mount -o ro "$p" "$mountpoint" 2>/dev/null && echo "mounted $p -> $mountpoint" || true
      # 如果挂载成功，查找网络脚本
      if mount | grep -q "$mountpoint"; then
         grep -nH -E 'IPADDR|BOOTPROTO|ifcfg-|ONBOOT|DEVICE|HWADDR' "$mountpoint/etc"/* 2>/dev/null || true
      fi
    done
    # cleanup
    for mp in "$OUTDIR"/mnt_*; do [ -d "$mp" ] && umount "$mp" 2>/dev/null || true; done
    qemu-nbd -d /dev/nbd0 || true
  fi
else
  echo "  qemu-nbd not installed; skipping mount step."
fi

# 6. 记录命令（可复现）
echo "sha256sum $IMG" > "$OUTDIR/commands.txt"
echo "strings $IMG | egrep -n 'IPADDR|BOOTPROTO|ifcfg-|ONBOOT|DEVICE|HWADDR|PASSWORD|DefaultPassword|ssh-rsa|BEGIN RSA PRIVATE KEY' > strings_hits.txt" >> "$OUTDIR/commands.txt"
sha256sum "$OUTDIR/commands.txt" > "$OUTDIR/commands.txt.sha256"

echo "[*] done. Results in $OUTDIR"
```

# 脚本 B — 内存镜像快速检测（`mem_quick.sh`）

保存为 `mem_quick.sh`，`chmod +x mem_quick.sh`，用法 `./mem_quick.sh pc.dmp [PID]`
（会跑 vol 的常用插件：pslist、lsadump、hashdump、vadregexscan）

```bash
#!/bin/bash
set -euo pipefail

IMG="$1"
PID="${2:-}"
TIMESTAMP=$(date +%Y%m%d_%H%M%S)
OUTDIR="mem_report_${TIMESTAMP}"
mkdir -p "$OUTDIR"

# 1. sha256
sha256sum "$IMG" > "$OUTDIR/$(basename $IMG).sha256"

# 2. 列进程（找 PID）
echo "[*] listing processes..."
vol -f "$IMG" windows.pslist.PsList > "$OUTDIR/pslist.txt" 2>&1

# 3. lsadump -> 查 DefaultPassword / LSA secrets
echo "[*] running lsadump..."
vol -f "$IMG" windows.lsadump.Lsadump > "$OUTDIR/lsadump.txt" 2>&1
grep -n -E 'DefaultPassword|DefaultUserName|LsaSecret|DPAPI' "$OUTDIR/lsadump.txt" > "$OUTDIR/lsadump_hits.txt" || true

# 4. hashdump（NTLM/hash）
echo "[*] extracting hashes (hashdump)..."
vol -f "$IMG" windows.hashdump.Hashdump > "$OUTDIR/hashdump.txt" 2>&1 || true

# 5. vadregexscan: email/token 搜索（如果提供 PID 则限定 PID）
PAT="[A-Za-z0-9._%+\-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}"
if [ -n "$PID" ]; then
  echo "[*] VadRegExScan for PID $PID ..."
  vol -f "$IMG" windows.vadregexscan.VadRegExScan --pid "$PID" --pattern "$PAT" > "$OUTDIR/vad_email_pid${PID}.txt" 2>&1 || true
else
  echo "[*] VadRegExScan for all processes (may be slow)..."
  vol -f "$IMG" windows.vadregexscan.VadRegExScan --pattern "$PAT" > "$OUTDIR/vad_email_all.txt" 2>&1 || true
fi

# 6. 生成 commands.txt 与哈希
echo "vol -f $IMG windows.pslist.PsList" > "$OUTDIR/commands.txt"
echo "vol -f $IMG windows.lsadump.Lsadump" >> "$OUTDIR/commands.txt"
echo "vol -f $IMG windows.hashdump.Hashdump" >> "$OUTDIR/commands.txt"
if [ -n "$PID" ]; then
  echo "vol -f $IMG windows.vadregexscan.VadRegExScan --pid $PID --pattern '$PAT'" >> "$OUTDIR/commands.txt"
else
  echo "vol -f $IMG windows.vadregexscan.VadRegExScan --pattern '$PAT'" >> "$OUTDIR/commands.txt"
fi
sha256sum "$OUTDIR/commands.txt" > "$OUTDIR/commands.txt.sha256"

echo "[*] done. Results in $OUTDIR"
```

# 具体操作步骤与命令例子

## 一：.docx / .docm（Office Open XML）静态查找（最快）

`.docx` 本质是 zip 包，里面的关系文件里通常含有外链（超链接、嵌入对象）。

```bash
# 复制文件，防止意外修改
cp suspicious.docx /tmp/

# 解压并搜索 http / https / microsoft: shell 的外链
unzip -q /tmp/suspicious.docx -d /tmp/docx_unpacked
grep -R --line-number -E "http[s]?://|mailto:|www\.|\.com|\.cn|\.ru" /tmp/docx_unpacked || true

# 常查位置：
# word/_rels/*.rels
# word/document.xml
# word/document.xml.rels
# word/embeddings/
```

通常 `word/_rels/*.rels` 或 `document.xml.rels` 会列出外部链接 `Target="http://evil.example.com/..."`。

---

## 二：.doc（二进制 OLE）与宏 — 用 oletools（推荐）

olevba 可以直接识别并尝试解混淆 VBA，列出可疑 URL。

```bash
# 直接分析（输出会标记可疑 URL / AutoExec 宏）
olevba.py suspicious.doc

# 如果是 docm/docx 带宏也能用 oletools 处理（一些版本）
olevba.py suspicious.docm
```

`olevba` 输出示例会列出 `URLs found:`、`AutoExec`、`suspicious` 等关键字。

若没有 `olevba.py` 命令（不同版本），通常包名是 `oletools`，也可用：

```bash
python3 -m oletools.olevba suspicious.doc
```

---

## 三：查看 OLE 中嵌入对象（图片/activex/flash/exe）

恶意域名可能藏在嵌入的对象（例如 embedded HTML/EXE/Flash）里：

```bash
oleobj.py suspicious.doc   # 提取并保存嵌入对象
# 然后对提取出的对象做 strings/grep 或二进制分析
strings extracted_obj.bin | egrep -o "([a-z0-9\-]+\.)+[a-z]{2,6}(:[0-9]{1,5})?(/[^\s\"]*)?"
```

## 四：oledump.py（浏览 .doc 各流）

oledump 可以展示每个流（stream），找到含宏或可疑脚本的流并导出：

```bash
# 列流
python oledump.py suspicious.doc

# 假设流号为 8（包含 VBA），导出：
python oledump.py -s 8 suspicious.doc > vba_stream.txt

# or dump all VBA
python oledump.py -v suspicious.doc  # -v 会尝试提取 VBA
```

## 五：通用提取域名正则（跨平台 one-liners）

下面是提取域名/URL 的通用正则，一般先用 `strings` 或 `grep -a` 读出可打印字符，再匹配域名：

```bash
# 从任意文件抽取 URL / 域名
strings suspicious.doc | egrep -o "https?://[A-Za-z0-9./?=&%_\-:#@~]+" | sort -u
# 仅域名（去掉协议/路径）
strings suspicious.doc | egrep -o "([a-zA-Z0-9][a-zA-Z0-9\-]{0,62}\.)+[a-zA-Z]{2,}" | sort -u
```

## 六：处理混淆与字符函数（VBA 常见混淆）

宏里常见 `Chr(104)&Chr(116)&"tp"`、`Replace`、`Join(Array(...))`、`StrReverse`、base64 等。用 `olevba` 可以尝试自动还原，但若失败，可用脚本还原常见模式。

示例：VBA 中 `Chr()` 拼接解码（手动或用脚本）

```python
# 这是一个快速示例：把 Chr(104)&Chr(116)... 这样的表达式转成字符串
import re
s = 'Chr(104)&Chr(116)&Chr(116)&Chr(112)'
nums = re.findall(r'ChrW?\((\d+)\)', s)
print(''.join(chr(int(n)) for n in nums))  # => 'http'
```

对于 `StrReverse("...")`、`Replace(...)` 等，按逻辑逆向执行即可。

## 七：批量自动化脚本（Python）—— 抽域名并去重

下面是一个可直接复制运行的 Python 脚本（仅静态提取可打印字符串并匹配域名/URL）：

```python
# save as extract_iocs.py
import re, sys

if len(sys.argv) < 2:
    print("Usage: python3 extract_iocs.py suspicious.doc")
    sys.exit(1)

fn = sys.argv[1]
data = open(fn, "rb").read()

# 取可打印字符段（避免二进制垃圾）
text = ''.join(ch for ch in data.decode('latin1', errors='ignore') if ord(ch) >= 32 and ord(ch) <= 126)

# 常用 URL 正则
url_re = re.compile(r"https?://[A-Za-z0-9./?=&%_\-:#@~]+")
dom_re = re.compile(r"([A-Za-z0-9][A-Za-z0-9\-]{0,62}\.)+[A-Za-z]{2,}")

urls = set(url_re.findall(text))
doms = set(dom_re.findall(text))

print("URLs:")
for u in sorted(urls):
    print(u)

print("\nDomains:")
for d in sorted(doms):
    print(d)
```

用法：

```bash
python3 extract_iocs.py suspicious.doc > iocs.txt
```

> 该脚本是静态、快速的初筛；对 VBA 混淆（Chr()、base64）需要先还原宏流或用 `olevba` 解码。

## 八：当遇到被 base64 / hex /大段字符串包裹时

很多攻击者会把脚本或 URL 编成 base64：

1. 在 `olevba` 的输出中查找长的 base64 字符串（长度 > 100）并尝试 `base64 -d`。
2. 也可能是十六进制，尝试 `xxd -r -p` 或 Python 解 hex。

示例解 base64（Linux）：

```bash
echo "base64string==" | base64 -d | strings | egrep -o "https?://[^\s']+"
```

找到域名/URL 后常做：

## 十：生成 IOC 报告（建议字段）

* 文件名、SHA256（或 MD5）、文件大小
* 抽取到的 URL 列表（去重）
* 抽取到的域名列表（去重）
* 哪个流/哪个文件（document.xml.rels / VBA module 名）包含该 URL
* 是否为 AutoExec 宏、是否含 Base64/Obfuscation 标志
* 建议处置（隔离样本，上报情报平台，阻断域名等）

# 常见问题 / 排查技巧

* **没找到 URL / 域名**：可能是通过 API 调用、动态生成或通过外部脚本。把 macro 内容完整导出，用脚本模拟 `Chr`/`Replace` 等函数。
* **域名被分段/变量拼接**：搜索 `ChrW(`、`Asc(`、`Join(`、`Split(`、`Replace(`、`&` 等模式。
* **域名在嵌入的 HTML / Flash 中**：用 `oleobj` 提取后再做 strings/grep。
* **想自动化对多个文件批量抽取**：把上面的 Python 脚本扩展成批处理，或用 `olevba` 的批量模式。

# 推荐流程模板（实战）

1. 在隔离环境复制样本。
2. 计算哈希（`sha256sum`）。
3. 对 `.docx` 先 `unzip` 并 grep。
4. 对 `.doc` 或有宏文件运行 `olevba.py`，保存输出。
5. 用 `oledump.py` 或 `oleobj.py` 检查嵌入对象。
6. 用 Python 脚本从文本和提取的流里匹配域名/URL，去重。
7. 对可疑域名做信誉查询（受控网络）。
8. 记录证据（哪些流/行包含 IOC），写简短报告并阻断/上报。
