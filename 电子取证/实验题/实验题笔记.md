# 1. 概览（练习题型 & 目标）

* **内存取证**：使用 Volatility（vol）导出 SAM/NTLM、LSA、DPAPI，查找 DefaultPassword、明文口令或会话 token。
* **磁盘镜像取证**（vmdk/RAW）：用 `strings`、`hexdump`、挂载/提取文件系统，搜索配置（IP、hostname、ifcfg-*）。
* **网络流量取证**（pcap）：用 Wireshark / tshark 追踪 HTTP 请求、Follow TCP Stream，找反弹 shell、webshell 上传、AES 密文等。
* **哈希破解**：把 NT/LM/MD5 等哈希拿到 `hashcat`/`john` 或在线工具（cmd5、hashes.com）破解明文。
* **文件修复**（损坏图片等）：用 `hexdump` 查看头部，补回魔数（PNG：`\x89PNG\r\n\x1a\n`），必要时修 CRC/补 IEND。
* **目标**：把各项技术串联，快速从镜像/流量/文件里定位证据并复原（如 flag）。💡

### E. 搜索镜像/raw 文件里的私有 IP

**你截图的“快速”命令（原样）**：

```bash
(base) MacBook-Pro-3:win zhangyuanyi$ strings win.raw | egrep -o "([0-9]{1,3}\.){3}[0-9]{1,3}" | egrep "^172\.16\.|^192\.168\.|^10\." | sort -u
```

示例输出（截图）：

```
10.0.0.0
10.0.0.1
10.18.10.394
192.168.0.1
192.168.163.2
192.168.38.153
```

> 注：此快速版不会校验每节是否 ≤255，所以会出现 `10.18.10.394`。

**改进（严格校验每个八位字节并筛私有网段）**：

```bash
strings win.raw \
  | egrep -o '([0-9]{1,3}\.){3}[0-9]{1,3}' \
  | awk -F. '($1<=255 && $2<=255 && $3<=255 && $4<=255){print $0}' \
  | egrep -E '^10\.|^192\.168\.|^172\.(1[6-9]|2[0-9]|3[0-1])\.' \
  | sort -u
```

示例输出（改进后）：

```
10.0.0.0
10.0.0.1
192.168.0.1
192.168.38.153
192.168.163.2
```

**统计频次（可判断出现热点）**：

```bash
strings win.raw \
  | egrep -o '([0-9]{1,3}\.){3}[0-9]{1,3}' \
  | awk -F. '($1<=255 && $2<=255 && $3<=255 && $4<=255){print $0}' \
  | egrep -E '^10\.|^192\.168\.|^172\.(1[6-9]|2[0-9]|3[0-1])\.' \
  | sort | uniq -c | sort -nr
```

示例输出：

```
 120 192.168.38.153
  45 10.0.0.1
  10 192.168.163.2
   2 10.0.0.0
```

* 进阶（排除 IPv6 与版本号噪声）：

```bash
strings win.raw | egrep -o '([0-9]{1,3}\.){3}[0-9]{1,3}(?![0-9])' | awk -F. '($1<=255 && $2<=255 && $3<=255 && $4<=255)' | sort -u
```

### H. 从 HTTP 请求里解密 AES(base64) payload（示例流程）

1. 把抓到的 base64 保存为 `payload.b64`。
2. 解码：`base64 -d payload.b64 > payload.bin`。
3. 解密（模式/IV 需按服务器代码确定；常见 AES-128-ECB/CBC）：

```bash
# 假设 AES-128-ECB，key 为 hex（示例）
openssl enc -aes-128-ecb -d -in payload.bin -out payload.dec -K 8aee7a9278112ca3...
```

查看解密后内容：

```bash
strings payload.dec | sed -n '1,80p'
```

* 注意：若使用 Java 的 `Cipher` 且 key/IV 来源于 session/随机串，需先抓取对应的 `bing_pass` 请求顺序拿到 key（如你题目中的 JSP 逻辑）。🔑

### I. 哈希破解 — 示例（hashcat / john / 在线）

**在线：** `https://www.cmd5.com/`、`https://hashes.com/zh/decrypt/hash`（可投放 NTLM/MD5 快速查询）
**hashcat（NTLM -m1000）**：

```bash
echo '7f21caca5685f10d9e849cc84c340528' > ntlm.txt
hashcat -m 1000 -a 0 ntlm.txt /path/to/rockyou.txt
```

示例输出（节选）：

```
7f21caca5685f10d9e849cc84c340528:anxinqi
```

**john**：

```bash
john --format=NT --wordlist=/path/to/rockyou.txt ntlm.txt
```

* 小贴士：
  * `hashid`/`hash-identifier` 识别哈希类型；`hashcat -m` 需匹配类型。
  * rockyou 过慢时，优先在线站点试水；命中后再本地验证。⚡

# 4. 常见陷阱与排错建议（务必写进笔记）

* `strings` 的误报：很多数字串、版本号、坐标会被误判为 IP/哈希，务必结合上下文（路径、端口、协议关键字）判断。
* 哈希类型误判：NTLM 与 MD5 易混淆（长度相近）。NTLM（常见于 Windows）用 `-m1000`；MD5 用 `-m 0`。
* LSA dump 输出多为 UTF-16LE（每个字节后跟 `00`），不要直接用 ASCII 读取。
* PNG 修复：仅补魔数通常能恢复，但若 IDAT/CODEC chunk 损坏或 IEND 缺失，可能还需逐 chunk 修复或用 `pngcheck`。
* pcap 中的 AES 密钥/IV 常散见于先前请求（session 建立），要按请求顺序还原（先 GET 获得 U，再 POST 解密 payload）。
* 在镜像搜索 IP 时，注意把非法四段（>255）剔除，避免误判（见 awk 校验）。
* 备忘：调查时间有限时，优先“能直接产出答案”的路径（hashdump、DefaultPassword、Follow Stream、IPADDR）。⏱️

# 5. 推荐的快速工作流（实战/考试推荐）

1. 内存：`vol windows.hashdump.Hashdump`（快速拿用户名 + nthash）。
2. 内存：`vol windows.lsadump.Lsadump` → grep `DefaultPassword`/`NL$KM` → 解码 UTF-16LE。
3. 磁盘：`strings ide0_disk.vmdk | egrep 'IPADDR|HOSTNAME'` 快速定位 IP/主机名。
4. 抓包：Wireshark Follow Stream 找 shell/上传；需要 CLI：`tshark -z "follow,tcp,raw,STREAM"`。
5. 文件损坏（PNG）：`hexdump` 查看头 → 补魔数 → 验证 → 若仍失败，逐 chunk 检查 CRC。
6. 哈希：先在线快速查（cmd5 等），再本地 `hashcat/john` 进行字典/规则破解。
7. 证据留存：保存原始 pcap/镜像/lsadump 输出/修复前后文件与过程说明。📁

# 7. 速查表与常见指纹（新增）

* **常见日志/文件路径**：
  * Linux：`/var/log/auth.log`、`/var/log/secure`、`~/.bash_history`、`/etc/ssh/sshd_config`
  * Windows：`C:\\Windows\\System32\\winevt\\Logs`（evtx），`AppData\\Roaming`（浏览器/IM）
* **协议/痕迹**：
  * 反向/反弹 shell 常见 UA：`curl/`、`Python-requests`、`powershell`
  * webshell 上传常见路径/参数：`upload`、`cmd=`、`eval`、`pass`、`shell.php`
* **快速正则片段**：

```bash
# IPv4（严格 0-255）

# URL
egrep -o 'https?://[^\s"']+'
# 邮箱
egrep -o '[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Za-z]{2,}'
```
